Responsiveness and adaptability

<head> There is a meta tag  on the page in the block viewport
The layout is made with respect to three break points:  320px,  768px and 1158px
All background and content bitmap images are responsive and support screens with densities  x1 of x2
Media function used for responsive background images min-resolution
Mobile First The approach and media function  used when writing styles min-width
Styles that are only needed within a certain range are wrapped in media queries  (min-width: ) and (max-width: ) or only (max-width: )
There is no unnecessary duplication of styles in media queries
To implement responsive graphics, use src + srcset (note: not picture + source + img)
